# Full Norm installer source snapshots

This directory makes each available installer source tree browseable directly on GitHub. All 23 original release tags and historical commits are unchanged. The version folders for those tags are byte-for-byte copies from their respective Git trees.

Additional source revisions from local archives:

- 1.6.11/: original source snapshot, text/source files only.
- 1.6.12-initial/: original pre-correction source snapshot.
- 1.6.12/: corrected runway-merged source, with build helpers and notes.

Version 1.6.15 is latest in the original tagged history. The 1.6.11 and 1.6.12 source snapshots document later archive discoveries, not historical tag rewrites.

No installer EXEs, private configs, embedded Norm source ZIPs or user plugins were added to these snapshots.
